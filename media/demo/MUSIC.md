# Music for the Financy demo video

`music.opus` is the music the Financy demo video's encoder lays under the video. No other video of
the owner's uses this track.

- Title: Sakura
- Author: Rafael Archangel
- Album: Library Music Vol. 1 (2017)
- Source:
  https://freemusicarchive.org/music/Rafael_Archangel/Library_Music_Vol1/Rafael_Archangel_-_Library_Music_Vol1_-_19_Sakura
- Copy downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:Rafael_Archangel_-_19_-_Sakura.ogg
  (file: https://upload.wikimedia.org/wikipedia/commons/5/5a/Rafael_Archangel_-_19_-_Sakura.ogg)
- Licence: CC0 1.0 Universal, a public domain dedication
  (https://creativecommons.org/publicdomain/zero/1.0/). Both pages above state it. It allows
  commercial use with no attribution; this file names the source anyway.

The file here is 90 seconds of the track starting at 0:08, where it is already steady, re-encoded
to Opus at 96 kbit/s, stereo, with all metadata removed and no other change. The video's encoder
trims it to the video's length, sets its level, and fades it in and out.
